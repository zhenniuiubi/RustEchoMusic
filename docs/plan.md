- 网关 `https://gateway.kugou.com` + `x-router` 路由到各服务
- Android 签名：`md5(OIlwieks28dk2k092lksi2UIkp + 排序参数串 + body + 盐值)`（lite 盐 `LnT6xpN3khm36zse0QzvmgTZ3waWdRSA`）

## 九、第四轮反馈修复：登录态打通 / 红心 API / 音量与进度条（2026-10-21）

### 关键发现：客户端必须用标准版（appid 1005）

之前客户端用「概念版 lite」（appid 3116 / clientver 11440），**登录态接口全部失败**：

| 接口                          | lite 结果          | 标准版结果       |
| --------------------------- | ---------------- | ----------- |
| `/v7/get_all_list`（用户歌单）    | 20017            | ✅ 返回 5 个歌单  |
| `/v1/user_verify`（播放授权）     | 35005            | ✅ 返回 auth   |
| `/tracker/v5/url`（VIP 歌曲地址） | error_code 31833 | ✅ 返回播放地址    |
| `/v1/get_my_userinfo`（用户详情） | 20006            | ✅ 返回昵称 / 头像 |

`crypto::sign_key` 也固定用**标准版盐值**（`57ae12eb...`）——用 lite 盐值算 key 会返回 31833。

### 本轮修复清单

| #  | 问题             | 根因 / 修复                                                                                                                                                                                                                                             |
| -- | -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1  | 登录后「我最喜爱」是空的   | 新增 `crates/echo-api/src/userlib.rs`：`/v7/get_all_list`（用户歌单）→ 找「我喜欢」→ `/v4/get_list_all_file_v3`（按 listid 取歌单歌曲，分页拉全）。实测拉到 **836 首**                                                                                                                |
| 2  | 收藏（红心按钮）只有本地效果 | 红心改为调云歌单 API：`/cloudlist.service/v6/add_song` 加歌、`/v4/delete_songs` 删歌。**删除的 fileid 必须用云歌单条目的 `fileid` 字段**（不是 `audio_id`、不是 `mixsongid`）——用错会返回 status=1 但不生效                                                                                      |
| 3  | 播放列表打不开        | 播放条队列按钮原本是空实现。新增右侧浮层面板 `render_queue_panel`：显示队列来源、序号、歌曲名/歌手/时长，点击切歌                                                                                                                                                                                |

| 8  | 榜单歌曲只有 1 首     | `/ocean/v5/rank/audio` 已 404 → 改用 `/openapi/kmr/v2/rank/audio`（POST + `kg-tid: 369`），并需带 `rank_cid`（从榜单列表取）                                                                                                                                         |

### mini 切歌修复（2026-10-25 第四轮）
